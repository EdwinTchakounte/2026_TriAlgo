La relation atomique

Emettrice, cable, receptrice

Une carte donne la forme. Une autre lui applique une transformation. Le resultat est une troisieme carte, deja presente dans le deck. C'est toute la grammaire du jeu, et elle ne change jamais.

Aucune carte n'a de role fixe. La receptrice d'une fusion devient l'emettrice de la suivante. C'est ce chainage qui fait naitre la difficulte, sans jamais ajouter une seule regle.

La progression

Cinq distances, une seule regle

La difficulte ne vient jamais du chronometre. Elle vient de la distance qui separe les trois cartes qu'on vous montre. En D1, elles forment une fusion directe. Au dela, elles sont prelevees le long d'une chaine : le lien existe toujours, mais il passe par des cartes que vous ne voyez pas.

D1 La fusion elle meme, les trois cartes se touchent 1trio
D2 Un maillon d'ecart, une carte intermediaire reste cachee 5trios
D3 Deux maillons, le lien cesse d'etre visible d'un coup d'oeil 14trios
D4 Trois maillons, il faut reconstruire la chaine de tete 27trios
D5 Quatre maillons, la limite du jeu 44trios

Une chaine de k fusions produit au plus C(2k,2) - 1 trios valides. Le trio doit contenir la carte finale, et ne jamais reproduire une fusion deja connue.

Apercu du deck

Autour d'une table

Le mode collectif

Les cartes physiques se posent sur la table. Chacun cherche, propose, defend son trio. Quand le groupe pense tenir une fusion, un seul telephone tranche : les trois numeros sont saisis, et la reponse tombe.

L'application ne joue pas, elle arbitre. Elle nomme les trois cartes et confirme la distance du trio. Le reste se passe entre joueurs, sans ecran.

Premiere partie

Trois etapes, une seule fois

  1. Installer l'application

    Le fichier APK s'installe directement sur Android. Votre telephone demandera d'autoriser une installation hors magasin : c'est normal pour une application distribuee de cette maniere.

  2. Activer votre deck

    Le code fourni avec votre jeu de cartes ouvre le deck correspondant. Il ne fonctionne que sur un appareil, ce qui garantit qu'un code vendu correspond bien a un joueur.

  3. Jouer, meme sans reseau

    Le deck est telecharge une fois, puis tout se passe sur l'appareil. Les questions sont fabriquees localement, les images restent en memoire, et une partie entiere se joue hors connexion.

Questions frequentes

Ce qu'on nous demande

Comment commencer une partie de MIXALGO ?

Installez l'application Android, creez votre compte, puis saisissez le code d'activation fourni avec votre jeu de cartes. Le code ouvre le deck correspondant et n'est utilisable que sur un seul appareil.

Faut il posseder les cartes physiques pour jouer ?

Non pour le mode solo, qui se joue entierement dans l'application. Les cartes physiques servent au mode collectif, ou les joueurs posent trois cartes sur la table et font verifier le trio par l'application.

MIXALGO fonctionne t il sans connexion internet ?

Oui. Le deck est telecharge une seule fois au premier lancement, puis les questions sont fabriquees sur l'appareil. Une partie entiere se joue sans reseau.

Que signifient les distances D1 a D5 ?

La distance mesure l'eloignement entre les cartes d'un trio dans le graphe du jeu. En D1 les trois cartes forment une fusion directe. A partir de D2, elles sont prelevees le long d'une chaine de fusions, ce qui rend le lien de moins en moins visible.

Combien de trios peut on former dans une partie ?

Une chaine de k fusions donne au plus C(2k,2) moins 1 trios valides, soit 1 en D1, 5 en D2, 14 en D3, 27 en D4 et 44 en D5. Un deck de 76 cartes depasse ainsi plusieurs centaines de questions distinctes.
